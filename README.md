# go-storage

## О проекте

`go-storage` — это in-memory key-value база данных с HTTP интерфейсом, возможностью персистентного хранения данных и автоматического удаления устаревших записей. Реализована 3 типа данных для хранения: скаляр, словарь и массив. Подробное описание методов для взаимодействия c каждым из них расоплогается [здесь](https://github.com/antonvlasov/BolshoiGolang/blob/main/project_requirements/requirements.md).

Реализация данного проекта была начата на курсе по backend разработке <i>"Большой Golang"</i>, который проходил осенью 2024 года в [НИТУ МИСИС](https://misis.ru/) при поддержке [ITAM](https://itatmisis.ru/).

<b>Основные характеристики хранилища:</b>

- Реализовано сохранение состояния (данных из хранилища) в `JSON` файл (атомарная запись файла на `Linux`) или Базу Данных `PostgreSQL`
- Реализован планировщик, удаляющий устаревшие записи через заданный в `env` интервал и сохраняющий состояние системы
- Реализована graceful остановка хранилища с сохранениеем состяния при получении сигнала `SIGINT` или `SIGTERM` от ОС

- При разработке применён принцип `SOLID`
- Применён паттерн `strategy`, позволяющий выбрать стратегию для сохранения данных из описанных в предыдущем пункте вариантов
- Написаны `unit-тесты` и бенчмарки для методов хранилища, предназначенных для работы с данными типа `scalar` и `dict`
- Написаны `API-тесты` для тестирования эндпойнтов, предназначенных для работы с данными типа `scalar`

## Развёртывание системы

Add ENV vars to `.env`. Example in `.env.example`.

[INPORTANT] Starting app from directory with `.env` and optionally `storage.json`

For run app from root project directory

```bash
go run cmd/storage/main.go
```

For build app and run

```bash
go build cmd/storage/main.go
./main
```
